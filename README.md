# From Rules to Conversations

## چرا امروز می‌توانیم با ماشین گفت‌وگو کنیم؟

یک مقاله تعاملی فارسی، راست‌به‌چپ و مستقل برای پروژه دوره بوژان؛ درباره کنار هم قرار گرفتن داده، محاسبه و روش‌های یادگیری. نسخه دوم بر پایه چهار فایل نسخه اولیه بازسازی شده است.

## هدف و سؤال اصلی

اگر ایده هوش مصنوعی قدیمی است، چرا دستیارهای زبانی عمومی زودتر عملی نشدند؟ هدف، توضیح علت‌ها برای مخاطب غیرمتخصص و ساخت نمونه‌کاری قابل انتشار است.

## روش تحقیق

ChatGPT برای گردآوری، مقایسه منابع، نگارش و پیاده‌سازی استفاده شده است. منابع اولیه و صفحات رسمی برای ادعاهای اصلی بررسی شده‌اند. ادعاهای آماری به گزارش و بازه مشخص محدودند. آمار گزارش‌های ۲۰۲۴ و ۲۰۲۵ به‌عنوان شواهد تاریخی آمده، نه تازه‌ترین وضعیت ۲۰۲۶.

بازبینی انسانی هنوز انجام نشده است. برای رعایت صادقانه معیار آموزشی، صاحب پروژه باید متن را بخواند، تغییرها/تأییدها را در [editorial-review.md](editorial-review.md) ثبت کند و سپس وضعیت صفحه را به‌روزرسانی کند. بازنویسی توسط AI را ویرایش انسانی معرفی نکنید.

## ساختار محتوا

۳. توجه و ترنسفورمر
۴. هم‌افزایی داده، پردازش و آموزش
۵. پیش‌آموزش تا دستیار
۶. عوامل شتاب و محدودیت
۷. تفکیک شاخص‌های رشد
۸. آزمایش فکری بازگشت به ۲۰۱۰

جمع‌بندی، روش تحقیق و ۱۵ مرجع با تاریخ و پیوند در انتهای صفحه آمده‌اند.

## فناوری و تجربه

- HTML معنایی، CSS و JavaScript ساده؛ بدون ساخت، npm، API یا چارچوب.
- Vazirmatn و Inter محلی با مجوز OFL؛ همه تصاویر SVG اختصاصی و محلی.
- حالت روشن/تاریک با حفظ انتخاب؛ پیش‌فرض مطابق دستگاه.
- فهرست فصل‌ها، پیشرفت مطالعه، آشکارسازی هنگام اسکرول و احترام به کاهش حرکت.
- مثال‌های تعاملی قواعد و توجه؛ خروجی‌های ازپیش‌نوشته‌شده، نه مدل واقعی.
- متن و منابع بدون JavaScript نیز خوانده می‌شوند.
- پیوند پرش به محتوا، فوکوس صفحه‌کلید، متن جایگزین تصاویر و طراحی واکنش‌گرا.
- بدون ابزار تحلیل، ردیابی یا درخواست شبکه هنگام مطالعه؛ لینک منابع با انتخاب کاربر باز می‌شود.

## اجرای محلی

فایل `index.html` را باز کنید؛ یا از داخل پوشه اجرا کنید:

```sh
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. همه دارایی‌ها محلی‌اند و خود صفحه اینترنت لازم ندارد.

## انتشار روی GitHub Pages

۱. یک مخزن عمومی با نام `from-rules-to-conversations` بسازید.
۲. محتویات داخل پوشه را با **Add file → Upload files** به ریشه مخزن اضافه کنید؛ `index.html` باید در ریشه باشد، نه داخل یک پوشه اضافه. فایل ZIP را مستقیم آپلود نکنید.
۳. در **Settings → Pages → Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
۴. شاخه `main` و پوشه `/(root)` را انتخاب و Save کنید.
۵. پس از پایان انتشار، نشانی معمول برابر است با `https://YOUR-USERNAME.github.io/from-rules-to-conversations/`؛ نشانی قطعی را از همان صفحه Pages بردارید.
۶. برای تصویر پیش‌نمایش شبکه‌های اجتماعی، نشانی قطعی را در دستور زیر بگذارید و `index.html` اصلاح‌شده را دوباره آپلود کنید:

```sh
python3 configure_site.py https://YOUR-USERNAME.github.io/from-rules-to-conversations/
```

این فرمان canonical، `og:url` و نشانی مطلق `og:image` را تنظیم می‌کند. تا پیش از مشخص شدن مقصد، نشانی ساختگی وارد صفحه نشده است. خود سایت پیش از این مرحله هم کار می‌کند؛ تکمیل پیش‌نمایش اشتراک‌گذاری به آن وابسته است.

راهنمای رسمی: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
